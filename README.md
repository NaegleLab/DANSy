# Domain Architecture Network Syntax (DANSy)

This is the development branch of DANSy that includes additional aspects of DANSy still under active development. Included in this is an application of DANSy to differential gene expression results called deDANSy. The current implementation is subject to change and may not reflect future versions.

If you want the stable version of DANSy, please return to the main branch. If you use DANSy please cite our [bioRxiv paper](https://doi.org/10.1101/2024.12.04.626803), which contains further details and specific applications of the code provided here.
